# Serifa Music — Personalização

Esta pasta reúne os arquivos externos utilizados para personalizar
a aparência do Serifa Music.

A integração com o sistema de aparência já está implementada.

## Guia completo

Consulte [GUIA_PERSONALIZACAO.md](GUIA_PERSONALIZACAO.md)
para instruções, formatos, dimensões e exemplos.

## Configurações

- `colors.toml`: paleta de cores.
- `typography.toml`: famílias, tamanhos e pesos tipográficos.
- `components.toml`: dimensões dos componentes.
- `layout.toml`: dimensões da janela e espaçamentos.
- `splash.toml`: configuração da tela de abertura.
- `theme.qss`: estilos avançados da interface.
- `icons.json`: catálogo e associação dos ícones.

## Recursos gráficos

- `icons/`: arquivos SVG da interface.
- `images/`: imagens utilizadas na personalização.
- `logos/`: logotipos externos.

## Inventários

- `INVENTARIO_SVG.md`: catálogo dos arquivos SVG.
- `INVENTARIO_CORES.md`: levantamento das cores do projeto.

## Personalização

Preserve os nomes e caminhos dos arquivos ao substituir recursos.

Configurações TOML e JSON precisam manter sua sintaxe válida.
Após modificar arquivos de aparência, reinicie o aplicativo.

Faça cópias dos arquivos antes de alterações extensas.
