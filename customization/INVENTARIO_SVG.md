# Inventário de ícones — Serifa Music

Este documento lista os SVGs disponíveis para substituição.

## Como substituir um ícone

1. Abra a pasta `customization/icons/`.
2. Localize o arquivo desejado nesta lista.
3. Substitua o SVG mantendo o mesmo nome e caminho.
4. Preserve o `viewBox` original sempre que possível.
5. Use SVG vetorial. Evite inserir imagens rasterizadas dentro do SVG.

O catálogo de identificadores e estados está em `icons.json`.
